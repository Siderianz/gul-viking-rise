# Контекст проекта: сайт гильдии Viking Rise

## Кратко

Это статический многостраничный сайт для гильдии Viking Rise. Цель проекта - сделать красивый, понятный и постепенно расширяемый guild hub: заявки, гайды, достижения, медиа, структура королевства, контакты и полезные ссылки.

Проект лежит в `C:\Users\Sid\Desktop\gul`.

## Технологии

- Обычные HTML/CSS/JavaScript без сборщика.
- Общие стили: `styles.css`.
- Общая логика сайта: `script.js`.
- Данные гайдов: `guide-data.js`.

## Архитектура страниц

Шапка, меню, футер и переключатель языка теперь рендерятся из `script.js`. Это снижает риск рассинхронизации навигации между страницами.

Каждая HTML-страница все еще содержит базовую разметку шапки/футера как fallback, но при загрузке JavaScript заменяет ее централизованным вариантом.

В `script.js` есть:

- массив `pages` с картой страниц;
- объект `translations` для RU/EN;
- `renderSharedLayout()` для шапки, навигации и футера;
- `applyLanguage()` для текста, placeholder, aria-label, meta и Open Graph;
- `initLanguageGate()` для стартового окна выбора языка;
- `initLanguageControls()` для переключателя RU/EN в шапке.

## Языки

Поддерживаются:

- `ru`;
- `en`.

На главной странице показывается стартовое окно с двумя рунами. При обновлении главной оно появляется снова, чтобы пользователь мог заново выбрать язык.

На внутренних страницах применяется язык из `localStorage.guildLanguage`, либо русский по умолчанию.

Новые переводимые тексты нужно добавлять так:

1. В HTML поставить `data-i18n="key.name"`.
2. Для placeholder поставить `data-placeholder-i18n="key.name"`.
3. Для aria-label поставить `data-i18n-aria-label="key.name"`.
4. Добавить ключ в `translations.ru` и `translations.en` в `script.js`.

## Гайды

`guides.html` подключает:

1. `guide-data.js`;
2. `guide-render.js`;
3. `script.js`.

`guide-render.js` строит вкладки, секции, карточки, заметки, чипы и таблицы из данных `guide-data.js`. Интерфейс гайдов и названия листов частично локализованы. Сами данные из таблицы в основном остаются на исходном языке документа.

Кнопка основного действия в гайдах ведет на Google Sheet, а не на локальный Excel, чтобы не заставлять сайт отдавать файл около 94 MB.
